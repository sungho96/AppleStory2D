# 🍎 AppleStory 
캐릭터 이동/점프/공격, 몬스터 AI, 전투 루프, UI 등 “게임 플레이의 기본 골격”을 구현하는 것을 목표로 합니다.

> ⚠️ **주의(중요)**  
> 이 저장소는 **학습/포트폴리오 목적**으로 제작되었습니다.  

---

## 🎮 게임 소개
- **방식**: 2D 횡스크롤 기반 플레이(TopDown 아님)
- **목표**: 메이플 특유의 “가볍고 말랑한” 조작감과 전투 템포 재현
- **특징**: **로프/줄 매달리기(Climb/Hang) 모션**을 포함한 플랫폼 액션 감성 반영

---

## ✨ 주요 기능(구현/계획 포함)
### 플레이어
- **이동**: `W / A / S / D`
- 점프/낙하 및 공중 상태 전환
- 공격 입력 처리 및 애니메이션 연동(Idle/Move/Jump/Attack)
- 히트박스/피격 판정(Trigger/Collider)
- **로프/줄 상호작용**: 매달리기 진입/유지/이탈 + 전용 모션(계획)

### 몬스터
- 간단 AI(순찰/추적/공격/사망)
- 스폰/리젠(구역 단위 또는 시간 기반)
- 드랍(선택): 아이템/골드 등

### UI
- HUD: HP/MP/EXP 표시(선택)
- GameOver / Respawn(선택)
- 인벤토리 UI(선택)

---

## 🧩 기술 요소(요약)
- **Component 패턴** 기반 기능 분리(Controller / Stat / Combat 등)
- **Collider / Trigger**를 활용한 상호작용 & 피격 판정
- **Animation State**(Idle/Move/Jump/Attack/Hang 등) 중심으로 로직 구성
- **Manager 구조(선택)**: UI / Sound / Resource / Data 등 역할 분리
- 반복 생성이 많은 오브젝트(이펙트/몹)는 **Object Pooling(선택)** 적용

---

## 🎯 조작 방법
- 이동: W / A / S / D or 키보드**학습/포트폴리오 목적**으로 제작되었습니다.  
> 원작 게임 리소스(이미지/사운드/폰트 등)를 **저장소에 포함하거나 배포하지 않습니다.**  
> 저작권이 있는 리소스는 각 권리자에게 귀속됩니다.

## 🎯 조작 방법
- 이동: W / A / S / D or 키보드(화살표 키)
- 점프: Space
- 공격: Left Click
- 로프/줄 매달리기: `(예: Up 키 또는 W로 진입 / Space로 이탈 등 — 프로젝트 기준으로 수정)`
- 인벤토리: (예: I)
